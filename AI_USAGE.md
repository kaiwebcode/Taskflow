# AI Usage

## AI Tools Used

- ChatGPT
- CodeRabbit

## How AI Was Used

### ChatGPT

ChatGPT was used as a development assistance tool for:

- Debugging frontend and backend issues.
- Reviewing implementation approaches.
- Improving task filtering and validation.
- Troubleshooting API and deployment issues.
- Suggesting UI and responsive design improvements.
- Explaining technical concepts during development.

### CodeRabbit

CodeRabbit was used for automated code review through GitHub Pull Requests.

It was used to:

- Identify potential bugs and code quality issues.
- Review changed files.
- Suggest improvements to maintainability and readability.

All AI-generated suggestions were reviewed and tested before being accepted.

## Developer Responsibility

AI was used as an assistance tool, not as a replacement for development work.

The developer:

- Implemented and integrated the features.
- Reviewed generated suggestions.
- Debugged and modified the code.
- Tested the application locally.
- Verified the production deployment.
- Reviewed CodeRabbit recommendations before applying changes.
